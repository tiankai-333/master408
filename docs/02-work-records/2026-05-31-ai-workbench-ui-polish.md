## 经验总结

### 微信小程序 HTML 渲染

1. `{{variable}}` 插值会将 HTML 标签原样输出，不会解析。包含 HTML 的内容必须用 `<rich-text nodes="...">` 组件渲染
2. `rich-text` 的 `nodes` 属性接受 HTML 字符串，小程序会自动解析为节点树
3. `rich-text` 内的图片、表格等需要在 CSS 中额外约束（如 `max-width: 100%`），否则会溢出
4. 题号和富文本内容用 flex 布局并排时，题号 `flex-shrink: 0` 防止被压缩

### 快捷操作栏设计

1. 操作按钮放在输入框上方、聊天区下方，符合用户视线从下往上的操作习惯
2. 按钮要有足够的点击区域（微信建议最小 88rpx），`padding` 比纯调 `height` 更容易适配不同文字长度
3. 不同功能用不同底色区分（靛蓝=画像、绿=粘贴、灰=清空），降低认知成本
4. 粘贴功能用 `wx.getClipboardData` 一行就能实现，不需要用户长按输入框

### 组卷流程 UX

1. 顶部行预设显示数量（`· 3道`）会让用户误以为数量已固定，去掉后弹窗内的数量选择才被真正感知
2. 弹窗标题和按钮文字保持一致（都叫「AI组卷」），减少理解成本
