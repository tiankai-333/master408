正确答案：AC

【解析】
在抗日战争时期，毛泽东在《论持久战》《抗日游击战争的战略问题》等著作中系统论述了游击战争为什么从通常的战术问题上升为战略问题。其核心原因在于抗日战争的特殊性：

  1. 主要是在外线单独作战（A 正确）：抗日游击战争并非单纯在内线配合正规军作战，而是在敌人占领的后方（外线）独立开展作战，牵制、消耗敌人，具有战略上的独立性和主动性。
  2. 是大规模的（C 正确）：抗日战争中的游击战争遍及广大敌后地区，参与人数多、范围广，其规模和影响超越了战术层面，成为关系战争全局的重大行动。
  3. 抗日战争的主要作战方式在战略防御阶段是运动战，游击战起辅助作用；在战略相持阶段游击战上升为主要作战形式，但并非整个战争全过程都是“主要作战方式”，故 B 表述不准确。
  4. 游击战争在战略上具有进攻性，但在具体战斗中既有进攻也有防御，并非“是进攻战，而不是防御战”，故 D 错误。
    因此，符合题干“具有战略地位”的原因的选项为 A 和 C。
