正确答案：D

【解析】
题目描述了“天宫一号”与“神舟八号”成功实现空间交会对接的事件。这一成就意味着我国掌握了空间交会对接技术，这是建造长期载人空间站的关键技术之一。

  • A选项：表述过于绝对，虽然技术取得重大突破，但“完全成熟”不符合实际情况，且载人航天技术仍在持续发展。
  • B选项：我国当时仍是航天大国，向航天强国的转变需要更多系统性突破，仅一次交会对接成功不足以说明实现转变。
  • C选项：我国载人航天工程“三步走”发展战略的最后一步是建造空间站，此时（2011年）尚未完成，因此不符合。
  • D选项：空间交会对接是建造载人空间站的核心技术基础，此次任务的成功确实为后续建造空间站奠定了坚实技术基础，与题干内容直接对应。

因此，正确答案为 D。
