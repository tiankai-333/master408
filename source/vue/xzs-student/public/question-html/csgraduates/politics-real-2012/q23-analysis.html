正确答案：ABD

【解析】
发展基层民主是中国特色社会主义民主政治建设的重要内容，其核心在于保障人民群众在基层组织中依法直接行使民主权利。

  • 选项A：基层民主实践能够增强公民的民主意识和参与能力，提升全民的民族素养（此处“民族素养”更宜理解为公民素养或民主素养），从而为更高层次的民主发展积累经验、创造条件，因此表述正确。
  • 选项B：基层民主是社会主义民主体系的基础环节，通过基层实践巩固民主根基，被视为“基础性工程”，符合我国对基层民主的定位。
  • 选项C：基层民主主要涉及基层公共事务和公益事业的管理，如社区事务、村级自治等，而非直接管理国家事务。国家事务的管理主要通过人民代表大会制度等间接民主形式实现，因此该选项表述不准确。
  • 选项D：发展基层民主正是为了保障基层群众对身边公共事务和公益事业的管理权，例如通过村民委员会、居民委员会等组织形式直接参与，因此表述正确。

综上，符合题意的选项为A、B、D。
