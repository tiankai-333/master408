正确答案：ABD

【解析】
马克思主义在论证共产主义理想实现的必然性时，一方面依据社会形态更替的一般规律（历史唯物主义），另一方面通过对资本主义社会的具体剖析，从以下三个方面进行科学论证：

  1. A项正确：马克思主义通过分析资本主义的基本矛盾（生产社会化与生产资料私人占有之间的矛盾），指出资本主义制度的历史局限性，论证其只是人类历史发展的一个阶段性形态，具有“历史的暂时性”，必然被更高级的社会形态取代。
  2. B项正确：资本主义在发展中会不断孕育否定自身的因素（如生产社会化程度提高、无产阶级壮大、经济危机周期性爆发等），这种“自我否定的趋势”为共产主义的实现创造了物质条件和社会力量。
  3. D项正确：马克思主义阐明，无产阶级（工人阶级）是资本主义的掘墓人，肩负着推翻资本主义旧世界、建立共产主义新世界的历史使命，这是实现共产主义的主体力量。
  4. C项错误：马克思主义并未具体设计资本主义灭亡和共产主义实现的具体途径与方式，而是指出历史发展的必然方向和基本原则。具体道路需结合不同国家的实际条件，因此该项不属于马克思主义通过剖析资本主义所“科学论证”的内容。

综上，本题答案为 ABD。
