【解析】
题目所引观点错误地将马克思主义理解为“经济决定论”，即认为经济是唯一决定因素，其他社会领域只是经济的被动反映。这歪曲了马克思主义关于经济基础与上层建筑辩证关系的原理。

  • A项正确：马克思主义认为历史发展是经济、政治、文化等多因素综合作用的结果，题目观点却将其简化为单一经济因素决定，属于歪曲。
  • B项正确：马克思主义强调经济基础与上层建筑之间存在相互作用，上层建筑也能反作用于经济基础，而题目观点将其歪曲为经济对上层建筑的机械单向作用。
  • C项正确：马克思主义承认经济在“归根到底”意义上起决定作用，但并非“唯一”决定作用，题目观点正是将“归根到底”的决定作用夸大為唯一决定作用。
  • D项错误：马克思主义认为意识形态具有能动作用，且这种作用可以是积极的也可以是消极的，但题目观点并未直接涉及对意识形态作用的歪曲，而是整体上将上层建筑视为完全消极被动。因此D项并非对该观点歪曲表现的确切概括。

综上，符合题意的选项为ABC。
