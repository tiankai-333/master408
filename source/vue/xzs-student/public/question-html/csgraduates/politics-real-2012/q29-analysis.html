【解析】
毛泽东在《关于正确处理人民内部矛盾的问题》的重要讲话中，系统阐述了社会主义社会的矛盾问题。

  • A项：讲话明确指出，社会主义社会同样充满着矛盾，矛盾是普遍存在的，这是分析社会主义社会问题的基本出发点。
  • B项：毛泽东提出，社会主义社会的基本矛盾仍然是生产关系和生产力、上层建筑和经济基础之间的矛盾，但这些矛盾在社会主义社会中具有非对抗性。
  • C项：强调社会主义社会的矛盾可以通过社会主义制度本身的自我调整和完善逐步解决，无需通过剧烈冲突或制度更替。
  • D项：讲话将正确处理人民内部矛盾确立为社会主义国家政治生活的主题，要求用民主、说服教育的方法解决人民内部矛盾，以团结全国人民建设社会主义。

因此，A、B、C、D四项均为讲话强调的核心观点，全部正确。
