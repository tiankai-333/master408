【答案】 最小值：0，最大值：8

【解析】 首先，求函数在区域内部的临界点。计算偏导数 fx​=2x−2xy2 和 fy​=4y−2x2y ，令其为零：

  • fx​=0 得 x=0 或 y2=1 ；
  • fy​=0 得 y=0 或 x2=2 。 结合条件，得临界点 (0,0) 、 (2​,1) 和 (−2​,1) ，函数值分别为 0 、 2 和 2 。

其次，考虑边界。边界由 y=0 （ −2≤x≤2 ）和半圆 x2+y2=4 （ y≥0 ）组成：

  • 在 y=0 上，函数化为 f(x,0)=x2 ，最小值为 0 （在 (0,0) ），最大值为 4 （在 (±2,0) ）。
  • 在半圆上，代入 x2=4−y2 得 f(x,y)=4−3y2+y4 。令 g(y)=y4−3y2+4 （ y∈[0,2] ），求导 g′(y)=4y3−6y ，得临界点 y=0 和 y=3/2​ 。函数值：在 y=0 时 f=4 ，在 y=3/2​ 时 f=7/4 ，在 y=2 时 f=8 .

比较所有点函数值：内部临界点值 0 和 2 ，边界值 0 、 4 、 7/4 、 8 ，故最小值为 0 ，最大值为 8 。
