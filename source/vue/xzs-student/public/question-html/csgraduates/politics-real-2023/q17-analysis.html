正确答案：ABC

【解析】
首先，题干通过马克思和恩格斯的论述强调了无产阶级领袖权威在革命斗争与政权建设中的必要性和重要作用。领袖权威的集中体现为能够引领方向、协调行动、凝聚力量，从而影响历史进程。

分析选项：

  • A. 引领社会发展的方向：领袖通过提出理论、制定策略，为无产阶级革命和建设指明方向，符合马克思、恩格斯关于领袖作用的论述。
  • B. 影响历史事件的进程：领袖的决策和权威直接关系到革命成败（如巴黎公社教训），能够加速或改变历史进程。
  • C. 凝聚人民群众的力量：恩格斯强调“没有权威就不可能有任何一致行动”，说明领袖能统一意志、团结群众，形成合力。
  • D. 创造人类社会的历史：此说法夸大了个人作用。历史是由人民群众创造的，领袖在其中起重要作用但非“创造”，马克思主义强调人民是历史的创造者。

因此，符合题意且表述准确的是 ABC。
