正确答案：C

【解析】 给定条件 P(B∣A)=P(B∣A) ，由条件概率定义， P(B∣A)=P(A)P(AB)​ 和 P(B∣A)=P(A)P(BA)​ 。代入条件得：

P(A)P(AB)​=P(A)P(BA)​

其中 P(BA)=P(B)−P(AB) 和 P(A)=1−P(A) ，所以：

P(A)P(AB)​=1−P(A)P(B)−P(AB)​

解方程：

P(AB)(1−P(A))=P(A)(P(B)−P(AB))

P(AB)−P(AB)P(A)=P(A)P(B)−P(A)P(AB)

P(AB)=P(A)P(B)

因此， P(AB)=P(A)P(B) ，即事件 A 和 B 相互独立，故选项 C 正确。选项 A 和 B 涉及 P(A∣B) 和 P(A∣B) ，当 A 和 B 独立时， P(A∣B)=P(A) 和 P(A∣B)=P(A) ，但 P(A) 不一定等于 P(A) ，因此 A 和 B 不一定成立。选项 D 与推导结果矛盾。
