1）算法的基本设计思想

本算法题属于送分题，题干已经告诉我们算法的思想。对于采用邻接矩阵存储的无向 图，在邻接矩阵的每一行（列）中，非零元素的个数为本行（列）对应顶点的度。可 以依次计算连通图 G 中各顶点的度，并记录度为奇数的顶点个数，若个数为 0 或 2，则 返回 1，否则返回 0。

2）算法实现

int isExistEL(MGraph G) {
  // 统计度为奇数的定点个数
  int count = 0;
  for (int v = 0; v < numVertices; v++) {
    // 该顶点的度
    int degree = 0;
    for (int e = 0; e < numEdges; e++) {
      if (Edge[v][e] == 1) {
        degree++;
      }
    }
    if (degree % 2 == 1) {
      count++;
    }
  }
  if (count == 0 || count == 2) {
    return 1;
  }
  return 0;
}

3）时间和空间复杂度

算法需要遍历整个矩阵，所以时间复杂度为 O(n2) ，空间复杂度为 O(1) 。
