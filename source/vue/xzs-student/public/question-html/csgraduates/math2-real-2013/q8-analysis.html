第二个矩阵的特征值为 2,b,0 ，则原矩阵的迹为 2+b+0=2+b 。
原矩阵的迹为 1+b+1=b+2 ，满足迹相等。

原矩阵行列式为 0 （因为第三个特征值为 0 ）。

1×(b×1−a×a)−a×(a×1−a×1)+1×(a×a−b×1)=b−a2+0+a2−b=0
