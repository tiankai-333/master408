正确答案：C

【解析】
事件 A 和 B 同时出现的概率 P(AB)=0 ，表示 A 和 B 同时发生的概率为 0 ，但这并不一定意味着 AB 是不可能事件。
在概率论中，概率为 0 的事件不一定是不可能事件，例如在连续概率分布中，某个点的事件概率为 0 ，但该点可能发生。
因此， AB 未必是不可能事件，选项 C 正确。

  • 选项 A 错误，因为 P(AB)=0 并不一定表示 A 和 B 不相容（如果不相容，则 AB 必须是不可能事件）。
  • 选项 B 错误，因为 P(AB)=0 不一定意味着 AB 是不可能事件。
  • 选项 D 错误，因为 P(AB)=0 并不要求 P(A)=0 或 P(B)=0 ，例如在非独立事件中， P(A) 和 P(B) 均大于 0 时， P(AB) 也可能为 0 。
