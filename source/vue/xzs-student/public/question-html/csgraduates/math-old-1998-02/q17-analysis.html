【解析】 曲线 y=x−1​ 的定义域为 x≥1 。过原点作该曲线的切线，设切点为 (a,a−1​) ，则切线斜率为 y′=2a−1​1​ 。切线方程为 y−a−1​=2a−1​1​(x−a) 。由于切线过原点 (0,0) ，代入得：

−a−1​=2a−1​1​(−a)

简化得：

a−1​=2a−1​a​

两边乘以 2a−1​ ：

2(a−1)=a

解得 a=2 ，切点为 (2,1) ，切线方程为 y=21​x 。

由曲线 y=x−1​ 、切线 y=21​x 及 x 轴围成的平面图形如下：

  • 对于 x∈[0,1] ，区域上边界为切线，下边界为 x 轴。
  • 对于 x∈[1,2] ，区域上边界为切线，下边界为曲线。

该图形绕 x 轴旋转一周所得旋转体的表面积由切线旋转形成的曲面面积和曲线旋转形成的曲面面积组成。

切线部分： y=21​x ， x 从 0 到 2 。
y′=21​ ， 1+(y′)2​=1+41​​=25​​ 。
切线旋转面积：

St​​=2π∫02​y1+(y′)2​dx=2π∫02​21​x⋅25​​dx=2π⋅45​​∫02​xdx=2π⋅45​​⋅24​=π5​​

曲线部分： y=x−1​ ， x 从 1 到 2 。
y′=2x−1​1​ ， 1+(y′)2​=1+4(x−1)1​​=2x−1​4x−3​​ 。
曲线旋转面积：

Sc​=2π∫12​y1+(y′)2​dx=2π∫12​x−1​⋅2x−1​4x−3​​dx=π∫12​4x−3​dx

计算积分： 令 u=4x−3 ，则 du=4dx ，当 x=1 时 u=1 ，当 x=2 时 u=5 ：

∫12​4x−3​dx=41​∫15​u1/2du=41​⋅32​u3/2​15​=61​(53/2−1)=61​(55​−1)

所以：

Sc​=π⋅61​(55​−1)=6π​(55​−1)

总表面积：

S=St​+Sc​=π5​+6π​(55​−1)=66π5​​+65π5​​−6π​=6π​(115​−1)

因此，旋转体的表面积为 6π​(115​−1) 。
