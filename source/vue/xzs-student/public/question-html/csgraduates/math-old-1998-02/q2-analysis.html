【解析】 曲线 y=−x3+x2+2x 与 x 轴的交点由方程 −x3+x2+2x=0 解得，即 x(x2−x−2)=0 ，所以交点为 x=−1,0,2 。
在区间 [−1,0] 上，函数值为负；在区间 [0,2] 上，函数值为正。因此，所求面积为

A=∫−10​∣y∣dx+∫02​∣y∣dx=∫−10​(−y)dx+∫02​ydx.

计算第一积分：

∫−10​−(−x3+x2+2x)dx​=∫−10​(x3−x2−2x)dx=[4x4​−3x3​−x2]−10​=0−(41​+31​−1)=125​.​

计算第二积分：

∫02​(−x3+x2+2x)dx​=[−4x4​+3x3​+x2]02​=(−416​+38​+4)−0=38​.​

A=125​+38​=125​+1232​=1237​.
