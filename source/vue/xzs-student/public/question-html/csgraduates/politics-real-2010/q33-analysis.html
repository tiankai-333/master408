  2. B项正确：该协议是落实中国—东盟战略伙伴关系的重要举措，通过深化经贸合作提升了双方关系的水平，符合当时双方“面向和平与繁荣的战略伙伴关系”的定位。
  3. C项正确：协议签署时正值全球金融危机后，中国与东盟加强投资合作有利于促进区域经济一体化，增强经济活力，从而对地区和全球经济复苏产生积极影响。
  4. D项错误：中国—东盟自贸区是区域自贸安排，但《投资协议》仅涉及中国与东盟之间的投资规则，并未直接为涵盖中日韩等国的“东亚自由贸易区”（即东亚区域全面经济伙伴关系等更大范围安排）提供法律保障。东亚自贸区的构建需多方另行谈判。
