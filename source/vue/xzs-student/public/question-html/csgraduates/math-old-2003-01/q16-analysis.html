【答案】
(1) 汽锤击打桩3次后，可将桩打进地下 a1+r+r2​ 米。
(2) 汽锤至多能将桩打进地下 1−r​a​ 米。

【解析】
(Ⅰ) 建立坐标系，地面作为坐标原点，向下为 x 轴正向。设第 n 次击打后，桩被打进地下 xn​ ; 第 n 次击打时，汽锤所作的功为 Wn​ (n=1,2,3,⋯) 。由题设，当桩被打进地下的深度为 x 时，土层对桩的阻力的大小为 kx ，汽锤所作的功等于克服阻力所做的功，所以

W1​=∫0x1​​kxdx=2k​x12​,W2​=∫x1​x2​​kxdx=2k​(x22​−x12​),

W3​=∫x2​x3​​kxdx=2k​(x32​−x22​).

又 W2​=rW1​, W3​=rW2​=r2W1​, x1​=a ，所以

2k​x32​=W1​+W2​+W3​=(1+r+r2)W1​=(1+r+r2)2k​a2.

于是 x3​=a1+r+r2​ 。

(Ⅱ) 和 (Ⅰ) 类似可得

2k​xn2​=W1​+W2​+⋯+Wn​

=(1+r+⋯+rn−1)W1​=(1+r+⋯+rn−1)2k​a2.

从而求得

xn​=a1+r+⋯+rn−1​=a1−r1−rn​​.

由于 0<r<1 ，所以 limn→∞​xn​=1−r​a​ .
