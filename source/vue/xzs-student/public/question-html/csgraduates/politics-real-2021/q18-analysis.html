正确答案：BD

【解析】

  1. 题干通过“人的免疫系统与自然环境之间的关系”引出话题，强调自然环境（温度）变化会影响病原体的适应性，进而影响人体免疫系统的效能，这说明自然环境为人类生存和发展提供了基础条件，是人类活动的重要前提，因此 B 项正确。
  2. A 项“自然环境对人类发展具有决定性作用”说法片面。虽然自然环境有重要影响，但题干并未体现其“决定性”，且人类社会发展还受社会规律、生产力等因素影响，故 A 项不选。
  3. C 项“人类只能适应自然环境变化而不能改变”表述绝对化，与事实不符，人类可以通过科学技术等手段改变自然环境（如调节温度、治理环境），因此 C 项错误。
  4. D 项指出人类既受自然环境制约，也能改变自然环境，符合题干中“免疫系统与自然环境相互作用”的辩证关系，也符合客观事实，因此 D 项正确。

综上，本题正确答案为 BD。
