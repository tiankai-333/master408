正确答案：C
本题间接考察 信道利用率。考虑制约甲的数据传输速率的因素，首先，信道带宽能直接制约数据的传输速率，传输速率一定是小于等于信道带宽的；其次，主机甲、乙之间采用后退 N 帧协议，那么因为甲、乙主机之间采用后退 N 帧协议传输数据，要考虑发送一个数据到接收到它的确认之前，最多能发送多少数据，甲的最大传输速率受这两个条件的约束，所以甲的最大传输速率是这两个值中小的那一个。甲的发送窗口的尺寸为 1000，即收到第一个数据的确认之前，最多能发送 1000 个数据帧，也就是发送 1000x1000B =1MB 的内容，而从发送第一个帧到接收到它的确认的时间是一个往返时延，也就是 50+50=100ms=0.1s，即在 100ms 中，最多能传输 1MB 的数据，因此，此时的最大传输速率为 1MB/0.1s=10MB/s=80Mbps。信道带宽为 100Mbps，所以答案为 min{80Mbps,100bps}=80Mbps，选 C.
