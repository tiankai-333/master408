【答案】
(1) 切点 A 的坐标为 (1,1)
(2) 过切点 A 的切线方程为 y=2x−1
(3) 所围平面图形绕 x 轴旋转一周所成旋转体的体积为 30π​

【解析】
(1) 设切点 A 的坐标为 (a,a2) ，其中 a>0 。曲线 y=x2 在点 A 处的切线斜率为 2a ，切线方程为 y=2ax−a2 。切线与 x 轴的交点为 B(2a​,0) 。
由曲线、切线和 x 轴所围图形的面积为：

A=∫0a/2​x2dx+∫a/2a​[x2−(2ax−a2)]dx

计算得：

∫0a/2​x2dx=24a3​,∫a/2a​(x−a)2dx=24a3​

所以 A=12a3​ 。给定 A=121​ ，解得 a3=1 ，即 a=1 。因此切点 A 的坐标为 (1,1) 。

(2) 将 a=1 代入切线方程 y=2ax−a2 ，得切线方程为 y=2x−1 。

(3) 所围图形绕 x 轴旋转的体积为曲线 y=x2 从 x=0 到 x=1 绕 x 轴旋转的体积减去切线 y=2x−1 从 x=21​ 到 x=1 绕 x 轴旋转的体积：

V=∫01​π(x2)2dx−∫1/21​π(2x−1)2dx=π∫01​x4dx−π∫1/21​(2x−1)2dx

计算得：

∫01​x4dx=51​,∫1/21​(2x−1)2dx=61​

所以 V=π⋅51​−π⋅61​=30π​ 。
