正确答案：ABCD

【解析】
本题考查的是影响资本积累规模的因素。资本积累即剩余价值资本化，其规模大小取决于多个方面：

  1. 利用资本与所费资本之间的差额（A项）：利用资本是指实际发挥作用的全部资本，所费资本是生产过程中实际消耗的资本（如固定资本折旧）。二者差额越大，意味着固定资本的无偿服务部分越多，越有利于扩大资本积累。

  2. 劳动生产率的高低（B项）：劳动生产率提高可以降低商品价值，使劳动力价值下降、剩余价值率上升；同时单位商品价值降低后，资本家可以在保持甚至提高消费水平的同时，增加积累基金。

  3. 资本家垫付资本的大小（C项）：在其他条件不变的情况下，垫付资本越大，可变资本比重不变时，可雇佣的工人越多，获得的剩余价值总量越大，积累规模也越大。

  4. 资本家对工人的剥削程度（D项）：剥削程度越高（如延长劳动时间、提高劳动强度、压低工资等），剩余价值率就越高，剩余价值量越大，积累规模也相应扩大。

因此，A、B、C、D四项均从不同角度决定了资本积累规模的大小，均正确。

答案：ABCD
