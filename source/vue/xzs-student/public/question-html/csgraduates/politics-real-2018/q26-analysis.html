正确答案：CD

【解析】
本题以我国对外开放的数据为背景，考查对“引进来”和“走出去”发展现状的理解。

  • A 选项错误：材料提到我国对外直接投资规模居世界第二，但并未说明“已经完全转向高端”。实际上，我国对外投资仍涵盖多种领域，“完全转向高端”的说法过于绝对且与事实不符。
  • B 选项错误：材料主要强调对外投资与吸引外资的成果，并未涉及防范经济风险和外部冲击能力“已经形成”的相关信息，该表述缺乏依据。
  • C 选项正确：材料指出“高技术服务业实际使用外资同比增长86%”“高附加值及服务行业外国直接投资流入量持续增长”，说明我国吸引外资的结构在优化、质量在提升。
  • D 选项正确：材料通过对外直接投资规模扩大、境外企业销售额和纳税就业数据，以及吸引高技术外资增长等，综合体现了我国国际投资合作水平在不断提高。

因此，符合材料表述的选项为 C 和 D。
