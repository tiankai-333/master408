正确答案：ACD

【解析】
量子纠缠现象表明，即使两个粒子在空间上相隔极远，测量其中一个粒子会立即影响另一个粒子的状态，这种关联不依赖于经典信息的传递。从马克思主义哲学视角分析：

  1. A项正确：量子纠缠是物质世界的一种客观现象，其存在不依赖于人的意识，进一步证明了世界统一于物质，体现了“世界的真正统一性在于它的物质性”。
  2. B项错误：量子纠缠是客观存在的联系，而非主观臆造；其发生具有必然的物理规律，并非偶然。
  3. C项正确：量子纠缠揭示了不同于经典物理的、非定域性的联系形式，体现了物质世界联系的复杂性和多样性。
  4. D项正确：量子纠缠作为一种普遍存在的物理现象，证明了物质世界中的联系是客观的、普遍的，不因空间距离而消失。

因此，正确答案为 ACD。
