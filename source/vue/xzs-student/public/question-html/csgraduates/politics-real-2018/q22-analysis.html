正确答案：ABD

【解析】
从现在到 2020 年是全面建成小康社会的决胜期，这一时期需要重点攻克制约全面建成小康社会的短板和难题。
党的十九大报告明确提出，要坚决打好防范化解重大风险、精准脱贫、污染防治三大攻坚战。

  • A 项“防范化解大风险” 对应“防范化解重大风险”，旨在维护经济金融安全和社会稳定。
  • B 项“污染治理” 对应“污染防治”，是生态文明建设的关键任务。
  • D 项“精准脱贫” 对应“精准脱贫”，是全面建成小康社会的底线任务和标志性指标。
    C 项“产业结构调整”属于经济转型升级的长期任务，并非决胜期必须集中攻坚的特定战役。
    因此，正确答案为 ABD。
