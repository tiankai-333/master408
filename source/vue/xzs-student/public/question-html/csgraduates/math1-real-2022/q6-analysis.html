分析 本题主要考查方程组的同解问题.

Ax=0 与 Bx=0 同解,说明 Ax=0 的解都是 Bx=0 的解,且 Bx=0 的解也都是 Ax=0 的解.

两方程组同解能反映这两个方程组的系数矩阵的秩的大小关系,但并不能反映系数矩阵的秩的大小.

解 设 y1​,y2​ 均为 n 维列向量, y=(y1​y2​​) 。

对 (AO​BB​) 和 (BO​AA​) 分别作初等行变换.

(EO​−EE​)(AO​BB​)=(AO​OB​) , (EO​−EE​)(BO​AA​)=(BO​OA​) 。

于是, (AO​BB​)y=0 等价于 (AO​OB​)y=0 ,即 {Ay1​=0,By2​=0.​

该方程组的解 y 满足 y=(y1​y2​​) ，其中 y1​ 为 Ax=0 的解, y2​ 为 Bx=0 的解.

同理, (BO​AA​)y=0 等价于 (BO​OA​)y=0 ,即 {By1​=0,Ay2​=0.​

该方程组的解 y 满足 y=(y1​y2​​) ，其中 y1​ 为 Bx=0 的解, y2​ 为 Ax=0 的解。

由于 Ax=0 与 Bx=0 同解,故选项C中的两个方程组同解.应选C.
