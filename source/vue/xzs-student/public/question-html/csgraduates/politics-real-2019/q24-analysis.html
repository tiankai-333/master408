【解析】

  1. A项正确。国家治理体系是制度基础，而治理能力是执行和运用制度的能力。提升治理能力能够更有效地发挥治理体系的效能，使制度优势转化为实际治理效果。
  2. B项正确。完善的国家治理体系能够为治理能力的提升提供制度支撑和规范指引，因此好的治理体系有助于提高治理能力。
  3. C项正确。国家治理体系与治理能力是相互依存、相互促进的有机整体，二者必须协同推进，不可偏废。
  4. D项错误。国家治理体系的完备性只是提升治理能力的必要条件而非充分条件。若缺乏有效的执行力、资源配置或干部素质等，即使体系完备，治理能力也可能不足。因此该表述过于绝对。

综上，本题答案为 ABC。
