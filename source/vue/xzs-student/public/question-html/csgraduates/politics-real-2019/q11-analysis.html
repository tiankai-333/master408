正确答案：B

【解析】
西安事变发生于1936年12月，张学良和杨虎城发动兵谏，要求蒋介石停止内战、一致抗日。中共中央在当时的主要政策是建立抗日民族统一战线，团结一切可以团结的力量共同抵御日本侵略。因此，中共中央促成西安事变和平解决的根本原因是 为了团结国民党共同抗日（选项B），这是当时民族矛盾上升为主要矛盾下的战略选择。

其他选项分析：

  • A 错误：中共中央实际上支持张学良、杨虎城停止内战、联合抗日的主张，但主张和平解决而非扩大冲突。
  • C 错误：当时中共中央的工作重心仍在农村，尚未向城市转移。
  • D 错误：虽然共产国际曾指示和平解决，但这是外因，并非根本原因；中共主要基于国内形势和民族利益独立作出决策。

故正确答案为B。
