正确答案：ABCD

【解析】
井冈山革命根据地的建立是毛泽东将马克思主义基本原理与中国革命实际相结合的重要实践。其选址原因包括：

  1. 群众基础较好（A项）：井冈山地区在大革命时期曾开展农民运动，群众对革命有一定认识和支持，便于发动和组织群众。
  2. 地势险要易守难攻（B项）：井冈山地处湘赣边界，山高林密、关隘众多，有利于开展游击战，应对国民党军队的“围剿”。
  3. 易于部队筹粮出款（C项）：当地物产相对丰富，能够为红军提供一定的粮食和物资补给，支撑长期斗争。
  4. 敌人统治力量薄弱（D项）：地处两省交界，国民党统治相对松散，军事力量薄弱，革命力量易于立足和发展。

这四点共同构成了井冈山作为革命根据地的有利条件，因此正确答案为 ABCD。
