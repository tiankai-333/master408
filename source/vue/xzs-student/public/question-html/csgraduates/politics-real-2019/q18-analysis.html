正确答案：ABCD

【解析】
本题旨在探讨严格控制 DNA 改变（如基因编辑技术应用）的原因，涉及科技伦理、实践哲学等多重维度。

  • A 项：科学具有双重性，既能造福人类，也可能因滥用或不可控带来危害（如生物安全风险、生态失衡）。因此，对 DNA 改变需谨慎控制，防范其潜在敌对性影响。
  • B 项：随意改变 DNA（尤其人类生殖系基因编辑）可能违背基本伦理原则（如尊严、平等、自然法则），触及道德底线，必须受到严格约束。
  • C 项：实践既追求真理（符合客观规律），也追求价值（满足人类需要）。DNA 改变的技术实践需兼顾科学真理性与人文价值性，盲目应用可能导致价值背离。
  • D 项：人类活动应同时遵循客观规律（合规律性）和主观目的（合目的性）。DNA 改造需在尊重生命规律的前提下，以实现人类福祉为目的，失控则可能破坏两者统一。

综上，四项分别从科学双重性、伦理边界、实践属性、人类活动原则等角度，完整阐述了严格控制 DNA 改变的必要性，故答案为 ABCD。
