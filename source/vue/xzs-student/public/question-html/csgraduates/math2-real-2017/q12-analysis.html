【答案】 f(x,y)=xyey

【解析】
给定偏导数 fx′​=yey 和 fy′​=x(1+y)ey ，我们可以通过积分求得原函数。

首先，对 fx′​ 关于 x 积分：

f(x,y)=∫yeydx=xyey+c(y),

其中 c(y) 是仅依赖于 y 的任意函数。

接下来，对 f(x,y) 关于 y 求偏导：

fy′​=xey+xyey+c′(y)=xey+xyey.

比较两边，可得：

c′(y)=0,

因此 c(y)=C ，其中 C 为常数。

利用初始条件 f(0,0)=0 ，代入原函数：

f(0,0)=0⋅0⋅e0+C=0⇒C=0.

最终得到：

f(x,y)=xyey.
