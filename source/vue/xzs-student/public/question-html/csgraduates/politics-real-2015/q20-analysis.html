正确答案：AD

【解析】

  1. 选项 A 正确：马克思在《资本论》中阐明了资本主义积累的一般规律，即资本有机构成提高导致对劳动力的需求相对减少，从而必然产生相对过剩人口。题干中“生产出相对的……过剩的工人人口”直接体现了这一规律。
  2. 选项 B 错误：相对过剩人口之所以是“相对的”，并非单纯因为“不为资本价值增殖所需要”，而是因为这部分人口相对于资本增殖的平均需要而言是过剩的，即资本积累过程中资本有机构成提高使得可变资本比例下降，劳动力需求相对减少。选项表述不够准确，且未抓住“相对”的本质是相对于资本增殖需要而言。
  3. 选项 C 错误：题干论断主要强调相对过剩人口是资本主义积累的必然产物和存在条件，并未直接涉及资本主义生产的周期性特征（如经济危机周期），因此该选项属于过度引申，与题干原意不符。
  4. 选项 D 正确：资本主义积累过程中，资本有机构成不断提高，相对过剩人口的规模会随着资本积累而扩大，马克思指出“工人人口本身在生产出资本积累的同时，也以日益扩大的规模生产出使他们自身成为相对过剩人口的手段”，这体现了失业规模总体扩大的趋势。

综上，符合题干论断的选项为 A、D。
