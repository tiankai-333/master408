【答案】 μ(μ2+σ2)

【解析】 本题涉及的主要知识点包括：

  1. 如果随机变量 X 和 Y 的相关系数 ρXY​=0 ，则称 X 与 Y 不相关。

  2. 若随机变量 X 与 Y 的联合分布是二维正态分布，则 X 与 Y 独立的充要条件是 X 与 Y 不相关。

  3. 如果随机变量 X 与 Y 相互独立，则有 E(XY)=EX⋅EY 。

在本题中，由于 (X,Y) 服从正态分布 N(μ,μ;σ2,σ2;0) ，说明 X 和 Y 独立同分布，故 X 与 Y2 也独立。

由期望的性质有：

E(XY2)=EX⋅EY2

又因为：

EX=μ

EY2=DY+(EY)2=σ2+μ2

所以最终结果为：

E(XY2)=μ(μ2+σ2)
