正确答案：ABC

【解析】
钓鱼岛自古以来就是中国固有领土。根据历史事实和国际法文件：

  1. 《开罗宣言》（1943年）明确规定，日本所窃取的中国领土，例如东北、台湾、澎湖列岛等，必须归还中国。钓鱼岛作为台湾附属岛屿，适用于这一规定。
  2. 《波茨坦公告》（1945年）第八条重申“《开罗宣言》之条件必将实施”，要求日本履行领土归还义务。
  3. 《日本投降书》（1945年）明确承诺接受《波茨坦公告》的全部条款，表明日本承认将台湾及其附属岛屿归还中国。
  4. 《德黑兰宣言》（1943年）主要涉及对德作战及战后合作安排，未涉及日本领土问题，因此与钓鱼岛归属无关。

综上所述，直接规定或确认钓鱼岛应随台湾归还中国的国际文件是《开罗宣言》《波茨坦公告》和《日本投降书》，故正确答案为 A、B、C。
