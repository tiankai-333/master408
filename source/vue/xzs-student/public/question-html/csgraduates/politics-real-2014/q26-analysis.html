【解析】
我国实施“走出去”战略，鼓励企业开展对外直接投资、跨国经营等国际化活动，其重要意义包括：

  1. 增强我国企业国际化经营能力（A项）：通过参与国际市场竞争，企业可以学习先进技术和管理经验，提升自身竞争力。
  2. 培育我国具有世界水平的跨国公司（B项）：对外直接投资有助于企业扩大全球布局，形成一批具有国际影响力的跨国企业。
  3. 充分利用国外资源（C项）：通过海外投资获取能源、原材料、技术、品牌和市场资源，弥补国内资源不足。
  4. 拓展我国经济发展空间（D项）：推动国内产业结构优化，缓解部分行业产能过剩问题，促进经济可持续发展。

以上四点均是我国企业“走出去”战略的重要目标与意义，故正确答案为 ABCD。
