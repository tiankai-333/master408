正确答案：ABCD

【解析】
中国（上海）自由贸易试验区于2013年9月29日正式启动，其设立的核心目标是为国家层面的改革开放进行压力测试和制度创新。具体任务主要包括：

  1. A. 为全国深化改革和扩大开放探索新途径，积累新经验
    自贸试验区被赋予“先行先试”的使命，通过制度创新探索可复制、可推广的经验，服务全国改革开放大局。

  2. B. 推动加快转变政府职能和行政体制改革
    自贸试验区推行负面清单管理、简政放权、事中事后监管等模式，旨在推动政府管理方式转变和行政效能提升。

  3. C. 促进转变经济增长方式和优化经济结构
    通过扩大服务业开放、促进贸易投资便利化、推动金融创新等措施，助力经济结构转型升级。

  4. D. 推动构建更加公平合理的市场经济体制
    自贸试验区着力营造国际化、法治化营商环境，促进各类市场主体公平竞争，完善市场经济体制。

综上，四个选项均属于上海自贸试验区建设的主要任务，因此正确答案为 ABCD。
