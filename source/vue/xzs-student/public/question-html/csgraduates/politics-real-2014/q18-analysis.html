正确答案：AD

【解析】
本题以史铁生《奶奶的星星》中的寓意切入，考查对个人在历史中作用的理解。题干强调每个活过的人都能为后人的路途“添些光亮”，即每个人都会对社会历史产生一定影响，但影响程度不同（巨星、火炬、烛光之别）。

  • A项正确：历史的发展是无数个人意志和行动相互交错、融合形成的“合力”的结果，每个人都在这个过程中发挥作用，与材料中“每个人活过的人都能添些光亮”的集体贡献思想一致。
  • B项错误：该项夸大杰出个人的作用，属于唯心史观的“英雄史观”。历史发展有其客观规律，不是由杰出个人单方面决定的，且材料并未强调个别人物决定走向。
  • C项错误：马克思主义认为，人民群众是历史的创造者，但并非“人人”都是创造者。历史创造者主要指推动社会发展的劳动者和进步力量，而反动人物则阻碍历史发展，故不能简单说“人人都是历史的创造者”。
  • D项正确：材料中“也许是一颗巨星，也许是一把火炬，也许只是一支含泪的烛光”正说明每个人对社会发展都有作用，只是作用大小不同，符合唯物史观关于个人对社会贡献具有差异性的观点。

因此，正确答案为 AD。
