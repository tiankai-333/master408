正确答案：BC

【解析】
第二次世界大战后，国家垄断资本主义的发展使资本主义国家加强了对经济的干预（如财政政策、货币政策等），经济调节机制从过去主要依靠市场自发调节转向更多运用国家手段。这种变化导致经济危机的形态也相应改变，主要表现在：

  1. 选项B正确：由于国家采取反周期措施（如危机时刺激需求、繁荣时抑制过热），经济危机四个阶段（危机、萧条、复苏、高涨）的界限变得模糊，交替过程不再像战前那样明显。
  2. 选项C正确：金融自由化和金融创新快速发展，使金融体系脆弱性增加，经济危机往往首先以金融危机的形式爆发（如2008年国际金融危机），并蔓延至实体经济。
  3. 选项A错误：经济危机的根本原因仍是资本主义基本矛盾（生产社会化与生产资料私有制之间的矛盾），贸易失衡可能加剧危机，但并非直接引发危机的主要根源。
  4. 选项D错误：经济全球化使危机更容易在国际间传导，破坏作用不限于发达资本主义国家，也会波及发展中国家乃至全球。

因此，本题正确答案为 BC。
