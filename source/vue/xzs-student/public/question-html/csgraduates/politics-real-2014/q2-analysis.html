正确答案：C

【解析】
普列汉诺夫的这段话通过对比“月食”（自然现象）和“社会革命”（社会现象），揭示了社会规律与自然规律的关键区别。自然规律（如月食）是自发实现的，不需要人的参与；而社会规律则必须通过人的自觉活动才能实现。社会革命作为社会规律发挥作用的一种形式，离不开人有意识的组织、动员和实践，因此“要进行社会革命就必须组织革命党”。

选项分析：

  • A 错误：社会规律同样具有重复性（如在相似条件下，生产关系适应生产力发展的规律会反复起作用），但重复性并非这里强调的重点。
  • B 错误：社会规律是客观的，不由人的意志决定，尽管它通过人的活动体现。
  • C 正确：社会规律需要通过人的有意识的实践活动来实现，这正是组织革命党的必要性所在。
  • D 错误：社会规律因涉及复杂的主体活动，往往比自然规律更难认识，而非更易认识。

因此，符合题干逻辑的选项是 C。
