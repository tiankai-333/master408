【答案】 (1) E(X)=0 ， D(X)=2
(2) 协方差为0， X 与 ∣X∣ 不相关
(3) X 与 ∣X∣ 不相互独立

【解析】 (1) 数学期望

E(X)=∫−∞+∞​xf(x)dx=∫−∞+∞​x⋅21​e−∣x∣dx.

由于被积函数 xe−∣x∣ 是奇函数，在对称区间上积分为零，因此

E(X)=0.

方差

D(X)=E(X2)−[E(X)]2=E(X2).

计算

E(X2)=∫−∞+∞​x2⋅21​e−∣x∣dx.

由于被积函数为偶函数，可得

E(X2)=2∫0+∞​x2⋅21​e−xdx=∫0+∞​x2e−xdx.

该积分是 Gamma 函数 Γ(3)=2!=2 ，因此

E(X2)=2,D(X)=2.

(2) 协方差

Cov(X,∣X∣)=E[X∣X∣]−E(X)E(∣X∣).

由 E(X)=0 ，得

Cov(X,∣X∣)=E[X∣X∣].

计算

E[X∣X∣]=∫−∞+∞​x∣x∣⋅21​e−∣x∣dx.

令 g(x)=x∣x∣ ，则 g(−x)=−x∣x∣=−g(x) ，故 g(x) 为奇函数，而 f(x) 为偶函数，因此 g(x)f(x) 为奇函数，在对称区间上积分为零，即

E[X∣X∣]=0.

因此协方差为 0， X 与 ∣X∣ 不相关。

(3) X 与 ∣X∣ 不相互独立。
理由如下：若相互独立，则对任意 Borel 集 A 和 B ，有

P(X∈A,∣X∣∈B)=P(X∈A)P(∣X∣∈B).

取 A=(1,+∞) ， B=(0,1) ，则

P(X>1,∣X∣<1)=0,

因为若 X>1 则 ∣X∣>1 ，不可能有 ∣X∣<1 。但

P(X>1)>0,P(∣X∣<1)>0,

所以

P(X>1)P(∣X∣<1)>0,

与独立性矛盾。因此 X 与 ∣X∣ 不相互独立。
