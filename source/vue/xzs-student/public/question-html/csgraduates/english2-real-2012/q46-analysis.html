【原文分析】
本文节选自《经济学人》2011年5月26日刊载的《流失还是获益？》一文，聚焦发展中国家人才外流现象及其对经济的影响。翻译时需注意以下难点：

  1. 文化专有名词（如“Silicon Valley”）需采用约定俗成的译法；
  2. 长难句的逻辑重组（如第二段末句的定语从句拆分）；
  3. 术语一致性（如“brain drain”统一译为“人才流失”）。

【参考译文】
发展中国家民众担忧移民问题时，通常忧虑的是本国精英流向硅谷或发达国家的医院与大学。这类人才正是英国、加拿大、澳大利亚等国试图通过优待高校毕业生的移民政策来吸引的对象。

大量研究表明，发展中国家受过良好教育者移民倾向尤为显著。2004年一项针对印度家庭的大规模调查显示，近40%的移民受过高中以上教育，而全印度25岁以上人口中该比例仅约3.3%。这种“人才流失”长期困扰贫困国家的政策制定者——他们担心这会损害经济发展，使国家失去急需的技术人才，这些人才本可在高校任教、在医院行医，或为本土工厂研发创新产品。

【翻译要点】

  1. “best and brightest”译为“精英”符合中文表达习惯；
  2. “immigration rules that privilege…”采用意译突出政策本质；
  3. 数据对比处保留原文精确性，同时通过“该比例”实现衔接；
  4. 末句通过增译“行医”“研发”等动词，使专业场景具体化。
