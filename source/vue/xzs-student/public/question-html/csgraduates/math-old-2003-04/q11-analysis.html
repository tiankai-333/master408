正确答案：B

【解析】
事件独立性的定义为 P(A∩B)=P(A)P(B) 。
若 AB=∅ ，即事件 A 与 B 有交集，但这并不能保证独立性。
例如，在样本空间等可能的情形下，若 A 与 B 有交集且满足 P(A∩B)=P(A)P(B) ，则它们独立；否则不独立。
因此，当 AB=∅ 时， A 与 B 可能独立，也可能不独立，故选项 B 正确。

  • 选项 A 错误，因为交集非空不一定独立。
  • 选项 C 错误：若 AB=∅ 且 P(A)>0 、 P(B)>0 ，则 P(A∩B)=0=P(A)P(B) ，此时不独立；但若 P(A)=0 或 P(B)=0 ，则等式成立，此时独立。
  • 选项 D 错误，因为当 P(A)=0 或 P(B)=0 时，事件独立。
