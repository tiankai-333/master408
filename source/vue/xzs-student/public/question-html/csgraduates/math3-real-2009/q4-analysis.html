正确答案：D

由定积分的几何意义， F(x) 表示 f(t) 从 0 到 x 与 t 轴围成的面积代数和。分析各区间特征：

① 当 x∈[0,1] 时， f(x)≤0 ，故 F(x) 单调递减且 F(x)≤0 。

② 当 x∈[1,2] 时， f(x)≥0 ，故 F(x) 单调递增。

③ 当 x∈[2,3] 时， f(x)=0 ，故 F(x) 为常函数。

④ 当 x∈[−1,0] 时， f(x) 为线性函数且 f(x)≤0 ，故 F(x) 为线性递增函数（因积分是累加负面积，斜率为负但 x 从 -1 到 0 时积分值增大）。

⑤ F(x) 连续。

结合选项，(D) 符合上述特征。
