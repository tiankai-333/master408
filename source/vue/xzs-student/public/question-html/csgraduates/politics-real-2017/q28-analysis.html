正确答案：ACD

【解析】

  1. A项正确：孙中山在辛亥革命后一直致力于维护共和制度，反对帝制复辟和军阀割据，强调国家统一，如发起“护法运动”等，体现了对民主共和国和统一事业的坚定维护。
  2. B项错误：北伐战争是由国共合作下的广州国民政府发动，主要领导者是蒋介石等人，旨在推翻北洋军阀统治。孙中山于1925年逝世，北伐战争始于1926年，故孙中山并未直接发动北伐战争。
  3. C项正确：1924年孙中山召开国民党一大，重新解释三民主义（发展为“新三民主义”），并正式确立“联俄、联共、扶助农工”三大政策，推动了国共合作和国民革命。
  4. D项正确：孙中山是辛亥革命的主要组织者和领导者，于1911年领导推翻清朝统治，建立了亚洲第一个共和国，结束了中国两千多年的封建帝制。

因此，符合孙中山伟大贡献的选项为 A、C、D。
