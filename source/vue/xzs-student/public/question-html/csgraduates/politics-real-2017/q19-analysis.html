正确答案：CD

【解析】
资本原始积累是指在资本主义生产方式确立之前，通过暴力手段迫使生产者与生产资料分离，从而形成大量自由劳动者和货币财富集中在少数人手中的过程。其本质是生产者和生产资料被强制分离的历史过程，为资本主义生产方式的产生创造了条件。

  • 选项A（用资本手段获取市场暴利）错误：资本原始积累发生在资本主义生产方式之前，此时资本主义生产关系尚未完全建立，“资本手段”本身正是原始积累的结果而非主要途径。
  • 选项B（用剥削手段榨取剩余价值）错误：剥削剩余价值是资本主义生产方式确立后的特征，属于资本主义积累而非原始积累。
  • 选项C（用野蛮手段进行殖民掠夺）正确：殖民掠夺是原始积累的重要途径，通过掠夺殖民地金银、资源、奴隶贸易等方式积累巨额货币财富。
  • 选项D（用暴力手段剥夺农民土地）正确：典型如英国的“圈地运动”，迫使农民与土地分离，成为无产者，为资本主义提供了劳动力。

因此，符合马克思对资本原始积累描述的途径是 C 和 D。
