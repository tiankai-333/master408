正确答案：A

【解析】
由于随机变量 X 与 Y 相互独立且同分布，且

P{X=−1}=P{Y=−1}=21​,P{X=1}=P{Y=1}=21​,

可计算各选项概率。

对于选项 A： P{X=Y} 表示 X 与 Y 取值相同，即 X=−1 且 Y=−1 或 X=1 且 Y=1 。由于独立，

P{X=−1,Y=−1}=21​×21​=41​,P{X=1,Y=1}=21​×21​=41​,

因此

P{X=Y}=41​+41​=21​,

选项 A 正确。

对于选项 B： P{X=Y}=1 显然错误，因为存在 X=Y 的情况。

对于选项 C： P{X+Y=0} 表示 X 与 Y 取值相反，即 X=−1 且 Y=1 或 X=1 且 Y=−1 。

P{X=−1,Y=1}=21​×21​=41​,P{X=1,Y=−1}=21​×21​=41​,

因此

P{X+Y=0}=41​+41​=21​=41​,

选项 C 错误。

对于选项 D： P{XY=1} 表示 X 与 Y 同号，即 X=−1 且 Y=−1 或 X=1 且 Y=1 。与选项 A 相同，

P{XY=1}=41​+41​=21​=41​,

选项 D 错误。

因此，唯一成立的选项是 A。
