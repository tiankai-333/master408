【命题分析】

本次翻译试题节选自英国儿童杂志《The Week Junior》2020年4月4日刊登的《诗歌的力量》一文。原文通过介绍英国浪漫主义诗人威廉·华兹华斯，进而探讨诗歌的艺术特质、历史渊源及表演属性。文本语言兼具文学性与普及性，虽无复杂句式结构，但需要考生在翻译时注意以下要点：

  1. 文学性表达的转换：原文运用了多项排比与抒情表达，需在译文中保留原文的韵律感
  2. 文化专有名词处理：“Romanticism"等术语需采用学界通用译法
  3. 语序调整与逻辑显化：英语中隐含的逻辑关系需通过汉语的显性连接手段予以呈现
  4. 动态对等原则：对于"capture"“transport"等动词，需寻找符合中文诗歌鉴赏语境的对应表达

【参考翻译】

18世纪末，威廉·华兹华斯以其歌咏自然的诗作声名鹊起。作为浪漫主义运动的奠基人之一，他所属的文学流派崇尚自然界的瑰丽神奇。

诗歌具有撼动人心的力量。其蕴含的能量与韵律能牢牢抓住读者，将他们带入别样天地，令其获得全新的审美视角。通过字斟句酌的精心编排，诗歌可呈现戏剧性的张力、妙趣横生的机锋、动人心魄的美感、催人泪下的深情与振奋人心的力量。

诗歌的起源虽已不可详考，但其存在已绵延数千年之久，甚至早于文字诞生之时。在漫长岁月中，诗歌承担着叙述故事、传承历史的使命。它与歌曲同根同源，即便形成文字，也始终保持着口头表演的传统。当诗歌被朗朗诵读之时，才真正被赋予生命。诵读同时促进理解，因文字间的韵律节奏在此过程中愈发清晰可辨。
