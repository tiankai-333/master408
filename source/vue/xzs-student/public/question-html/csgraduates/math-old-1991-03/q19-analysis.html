点 B 的横坐标为 31​ln2−1 ，点 C 的横坐标为 21​+31​ln2 。

【解析】
设点 B 的横坐标为 b ，点 C 的横坐标为 c 。由于 AB 和 DC 均垂直 x 轴，且点 A 在曲线 y=ex 上，点 D 在曲线 y=e−2x 上，则 ∣AB∣=eb ， ∣DC∣=e−2c 。
给定 ∣AB∣:∣DC∣=2:1 ，即 eb/e−2c=2 ，所以 eb+2c=2 ，取对数得 b+2c=ln2 。
梯形 ABCD 的面积 S 为：

S=21​(∣AB∣+∣DC∣)⋅(c−b)=21​(eb+e−2c)(c−b)

利用约束 b=ln2−2c ，代入面积公式：

S​=21​(eln2−2c+e−2c)(c−(ln2−2c))=21​(2e−2c+e−2c)(3c−ln2)=21​⋅3e−2c(3c−ln2)=23​e−2c(3c−ln2)​

令 S(c)=23​e−2c(3c−ln2) ，求导：

S′(c)=23​[e−2c⋅3+(3c−ln2)⋅(−2)e−2c]=23​e−2c(3−6c+2ln2)

设 S′(c)=0 ，得 3−6c+2ln2=0 ，解得 c=21​+3ln2​ 。
代入 b=ln2−2c ，得 b=ln2−2(21​+3ln2​)=31​ln2−1 。
