【答案】
P(A1​)=157​ ， P(A2​)=1514​

【解析】
从数字 0 到 9 中任选三个不同的数字，共有

C(10,3)=120 种可能。

  • 事件 A1​ ：三个数字中不含 0 和 5，即从其余 8 个数字中选 3 个，

    C(8,3)=56 种,P(A1​)=12056​=157​.

  • 事件 A2​ ：三个数字中不含 0 或 5（即至少缺少其中一个），等价于不同时包含 0 和 5。
    同时包含 0 和 5 的选法为：固定 0 和 5，再从其余 8 个数字中选 1 个，

    C(8,1)=8 种,P(同时含 0 和 5)=1208​=151​.

    因此

    P(A2​)=1−151​=1514​.

另一种方法：
设 B 为“不含 0”， C 为“不含 5”，则 A2​=B∪C 。

P(B)=120C(9,3)​=12084​,P(C)=12084​,P(B∩C)=P(A1​)=12056​.

由容斥原理得

P(B∪C)=12084​+12084​−12056​=120112​=1514​.
