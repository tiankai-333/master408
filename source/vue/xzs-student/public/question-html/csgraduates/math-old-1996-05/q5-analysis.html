【答案】 2411​

【解析】 每个零件的不合格概率为 Pi​=i+11​ ，因此合格概率为 1−Pi​=i+1i​ 。具体地：

  • 零件1合格概率： 21​
  • 零件2合格概率： 32​
  • 零件3合格概率： 43​

X 表示合格品个数，求 P{X=2} ，即恰好两个零件合格。考虑所有可能情况：

  1. 零件1和2合格，零件3不合格：概率为 21​×32​×41​=121​
  2. 零件1和3合格，零件2不合格：概率为 21​×31​×43​=81​
  3. 零件2和3合格，零件1不合格：概率为 21​×32​×43​=41​

将以上概率相加： 121​+81​+41​=242​+243​+246​=2411​ 。因此， P{X=2}=2411​ 。
