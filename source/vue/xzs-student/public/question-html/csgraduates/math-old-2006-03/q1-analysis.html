考虑极限 limn→∞​(nn+1​)(−1)n 。
首先，简化底数： nn+1​=1+n1​ ，因此表达式化为 (1+n1​)(−1)n 。
指数 (−1)n 在 n 为偶数时取值为 1，在 n 为奇数时取值为 -1。

  • 当 n 为偶数时， (−1)n=1 ，表达式为 (1+n1​)1=1+n1​ ，当 n→∞ 时， n1​→0 ，故极限为 1。
  • 当 n 为奇数时， (−1)n=−1 ，表达式为 (1+n1​)−1=1+n1​1​=n+1n​ ，当 n→∞ 时， n+1n​→1 ，故极限为 1。

由于在 n 为偶数和奇数时极限均为 1，因此整体极限为 1。
